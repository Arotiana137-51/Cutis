# Cutis

An iPhone app that scans a real body part with LiDAR, places a tattoo design on the 3D shape at real size, and shows how it looks when the body moves and as the body changes with weight, age and ink aging.

It is a reality check before a permanent tattoo, and a planning tool for people who already have tattoos. Tattoo artists use it to send previews to clients and print real-size stencils.

## Parts

- **iOS app** for clients and tattoo artists
- **Backend API** with workers for 3D processing
- **Admin panel** in the browser
