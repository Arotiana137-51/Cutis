# Cutis

Working name: **Tattoo Preview**. An iPhone app that scans a real body part with LiDAR, places a tattoo design on the 3D shape at real size, and shows how it looks when the body moves and as the body changes.

**Status: Phase 0 (pipeline proof).** The app is one screen that shows its version, the phone model and whether the phone has LiDAR. The point of this phase is that a build reaches a phone through TestFlight with no Mac involved.

## Layout

```
ios-app/                 The iPhone app
  Config/App.xcconfig    App name, bundle ID, Team ID: the one file to edit
  project.yml            Describes the Xcode project (generated by XcodeGen in CI)
  App/                   SwiftUI app code and assets
  Packages/AppCore/      Pure-Swift logic with unit tests (run on Linux)
  fastlane/              Signing and TestFlight upload
  scripts/               Checks that run on Linux before any macOS build
.github/workflows/       ios.yml: checks, then build, sign and upload
docs/                    Brief, setup guide, decisions, open questions
```

`backend/`, `admin-web/` and `infra/` arrive in later phases.
